# How to Ask for Programming Help Without Losing the Learning

## Good help request

```text
I'm working on project:
Milestone:
What I want to happen:
What happens instead:
Relevant code:
Exact compiler command and error:
What I think the cause might be:
Please explain the concept and give me one or two hints first. Don't rewrite the whole project.
```

## Ask in levels

1. **Concept:** "Explain what `fgets` returns and what can go wrong."
2. **Hint:** "Point me toward the likely bug without showing the fix."
3. **Review:** "Review this function for correctness and edge cases."
4. **Small example:** "Show a tiny independent example of this API."
5. **Solution review:** Only after a genuine attempt, ask to compare approaches and explain tradeoffs.

## Rules for AI-generated code

- Never keep code you cannot explain.
- Compile and test code yourself.
- Ask which assumptions the code makes.
- Ask for edge cases and failure modes.
- Rewrite a small portion from memory after understanding it.
- Do not paste secrets, passwords, access tokens, or private data into examples.
